# Digital Detective — Independent Learning Assignment

## 1. Introduction
The Digital Detective assignment is a comprehensive independent learning journey designed to build foundational computer science competencies through hands-on terminal workflows and documentation.

## 3. Topics Explored
* Hardware and software system components.
* Terminal navigation, directory structures, and file permissions.
* Operating system processes and resource monitoring.
* Python program execution, variables, and custom logic.
* Number systems (Decimal, Binary, Hexadecimal) and text encoding (ASCII & UTF-8).
* Version control workflows, branching, and Pull Requests with Git & GitHub.
* Network architectures (LAN, WAN), DNS resolution, and website request lifecycles.

## 4. How to Run the Number Converter
To execute the interactive Python number converter from its mission folder, run:
cd mission-05-numbers-data
python3 number_converter.py

## 5. Summary of What I Learned
Through this project, I gained practical proficiency in navigating Unix terminal environments, implementing version-controlled software development cycles, understanding how raw bytes and number systems represent data, and analyzing how data packets traverse modern computer networks.
